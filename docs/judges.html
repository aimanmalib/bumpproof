For judges

Everything here can be checked without an account or credits. The terminal replay needs the network once, to download the package.

Judge it in 2 minutes

  1. Open a run page and read the verdict, the journeys and the patch.

    github.com/aimanmalib/bumpproof #3 Fixed

  2. Replay the same run in your terminal:

    npx github:aimanmalib/bumpproof replay docs/runs/20261122-1830-1146

  3. Read the raw numbers in the JSON files:

    • docs/runs/*/run.json
    • census/results.json

Where to find the proof

  • Verdict rules src/compare.ts
  • Patch guards and their failing cases test/guards.test.ts
  • Docker sandbox flags src/sandbox.ts
  • Kane CLI output parser src/kane.ts
  • Decision log docs/02-DECISIONS.md

Untuk juri

Semua di sini boleh disemak tanpa akaun atau kredit. Ulang tayang terminal perlu rangkaian sekali, untuk memuat turun pakej.

Nilai dalam 2 minit

  1. Buka halaman larian dan baca keputusan, perjalanan dan patch.

    github.com/aimanmalib/bumpproof #3 Dibaiki

  2. Ulang tayang larian yang sama dalam terminal anda:

    npx github:aimanmalib/bumpproof replay docs/runs/20261122-1830-1146

  3. Baca angka mentah dalam fail JSON:

    • docs/runs/*/run.json
    • census/results.json

Di mana buktinya

  • Peraturan keputusan src/compare.ts
  • Pengawal patch dan kes gagalnya test/guards.test.ts
  • Bendera kotak pasir Docker src/sandbox.ts
  • Pembaca output Kane CLI src/kane.ts
  • Log keputusan docs/02-DECISIONS.md
