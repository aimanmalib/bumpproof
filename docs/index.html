Bumpproof

Dependabot says the bump is safe. Bumpproof makes Kane CLI prove it in a real browser.

  1. 1Build and start the app twice in a Docker sandbox: once on the base branch, once on the dependency bump.
  2. 2Kane CLI runs the same user journeys in Chrome against both.
  3. 3Plain code compares the two runs and gives a verdict. No model decides pass or fail.
  4. 4If the bump broke something, Claude Code writes a fix and Kane CLI runs the journeys again to prove it.

Status: being built during the KaneCLI Online Hackathon (12 to 26 November 2026). Nothing is measured yet. This page will show real runs and a census of real dependency pull requests once they exist.

Dependabot kata naik taraf itu selamat. Bumpproof meminta Kane CLI membuktikannya dalam pelayar sebenar.

  1. 1Bina dan hidupkan aplikasi dua kali dalam kotak pasir Docker: sekali pada cawangan asas, sekali pada naik taraf kebergantungan.
  2. 2Kane CLI menjalankan perjalanan pengguna yang sama dalam Chrome terhadap kedua-duanya.
  3. 3Kod biasa membandingkan dua larian itu dan memberi keputusan. Tiada model yang memutuskan lulus atau gagal.
  4. 4Jika naik taraf merosakkan sesuatu, Claude Code menulis pembaikan dan Kane CLI menjalankan perjalanan sekali lagi untuk membuktikannya.

Status: sedang dibina semasa KaneCLI Online Hackathon (12 hingga 26 November 2026). Belum ada apa-apa yang diukur. Halaman ini akan memaparkan larian sebenar dan banci PR kebergantungan sebenar bila ia wujud.
