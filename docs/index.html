Dependabot says the bump is safe. Bumpproof makes Kane CLI prove it.

Bumpproof builds your app twice in a Docker sandbox, once on the base branch and once on the bump. Kane CLI walks the same user journeys in Chrome against both. Plain code compares the runs. When the bump breaks a journey, Claude Code writes a fix and Kane CLI runs every journey again.

RunsFor judges

How a check runs

  1. 1

    Build base and bump

    Each side is installed, built and served in a locked-down container on the same port.

  2. 2

    Walk the journeys

    Kane CLI runs the same plain-English tests in Chrome against each side.

  3. 3

    Compare in code

    Exit codes and heal events decide: same, UI moved, or regression. No model decides.

  4. 4

    Fix and prove

    Claude Code edits files only. Guards check the patch. Kane CLI runs every journey again.

Run it on your own repository

Needs Node 20 or later, Docker, a Kane CLI login and Claude Code.

npm install -g --install-links github:aimanmalib/bumpproof
bumpproof doctor
bumpproof pr <owner>/<repo>#<number> --fix

GambaranLarianBanciUntuk juri

Dependabot kata naik taraf itu selamat. Bumpproof meminta Kane CLI membuktikannya.

Bumpproof membina aplikasi anda dua kali dalam kotak pasir Docker, sekali pada cawangan asas dan sekali pada naik taraf. Kane CLI menjalankan perjalanan pengguna yang sama dalam Chrome terhadap kedua-duanya. Kod biasa membandingkan larian itu. Bila naik taraf merosakkan satu perjalanan, Claude Code menulis pembaikan dan Kane CLI menjalankan setiap perjalanan sekali lagi.

LarianUntuk juri

Cara satu semakan berjalan

  1. 1

    Bina asas dan naik taraf

    Setiap sisi dipasang, dibina dan dihidupkan dalam kontena terkunci pada port yang sama.

  2. 2

    Jalani perjalanan

    Kane CLI menjalankan ujian bahasa biasa yang sama dalam Chrome terhadap setiap sisi.

  3. 3

    Banding dengan kod

    Kod keluar dan peristiwa penyembuhan menentukan: sama, UI beralih, atau regresi. Tiada model yang menentukan.

  4. 4

    Baiki dan buktikan

    Claude Code hanya menyunting fail. Pengawal menyemak patch. Kane CLI menjalankan setiap perjalanan sekali lagi.
