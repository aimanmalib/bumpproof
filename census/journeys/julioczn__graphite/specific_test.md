# Open the new connection form

Graphite is an Electron desktop app; this journey loads its built web view in a plain browser, without the desktop bridge.

## The connection screen loads
Verify a button "Nova conexão" and a section "Conexões salvas" are visible.

## Open the form
Click "Nova conexão". Verify a form is shown with the fields "Tipo de banco" and "Nome".
