# Legend and map projection

## The legend is shown
Verify a legend in the bottom-left corner shows the label "Visited".

## Switch to the globe
Click the button labelled "Earth" in the bottom-right controls. Verify the legend with "Visited" is still shown and no error screen appears.

## Switch back to the flat map
Click the button labelled "Map". Verify the legend with "Visited" is still shown.
