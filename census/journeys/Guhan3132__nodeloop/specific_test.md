# Read the tokens page and switch the theme

## The home page loads
Verify the heading "The UI patterns your AI agent is missing" is visible with a "Get started" link and a link that starts with "Browse".

## Open the tokens page
Click "Tokens" in the top navigation. Verify the heading "Tokens and theming" is shown and a table lists the row "Text on the page".

## Switch the theme
Click the button labelled "Switch to dark mode" or "Switch to light mode" in the header. Verify the page background changes between light and dark and the heading "Tokens and theming" is still visible.
