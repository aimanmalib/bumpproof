# Build an embed URL

## The builder shows its panels
Verify the heading "GitHub Top Languages Builder" is visible and the "Controls" and "Output" panels are shown with a chart preview.

## Type a host
Type "example.com" into the Host field. Verify the Embed URL field starts with "https://example.com/api/languages".

## Switch the theme to None
Select "None" in the Theme dropdown. Verify a "Colours" section appears with pickers labelled "Background" and "Text".
